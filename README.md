## 📖 About the Game

Welcome to the **Straw Hat Pirate Personality Quiz**, a text-based interactive Python game designed to discover which member of the legendary Straw Hat Pirates best matches your unique personality, morals, and life experiences.

Whether you share **Luffy's fearless curiosity** or **Zoro's disciplined determination**, this program uses a point-based scoring system to reveal your inner pirate soulmate! 🏴‍☠️

---

## ✨ Key Features

- 🧭 **14 Scenario-Based Questions** — Real-life dilemmas covering childhood, discipline, beliefs, empathy, and leadership.
- 🎯 **Dynamic Scoring System** — Each answer (A, B, C, or D) contributes to a final score that determines your result.
- ⚓ **10 Unique Endings** — Matches you with one of 10 iconic crew members.
- 📝 **Detailed Personality Descriptions** — Each result provides a specific character trait highlighting your strengths based on the character you matched with.
- 💻 **User-Friendly Interface** — Simple console-based input that anyone can run in a Python environment.

---

## 🎮 How to Play

1. The program starts by asking if you are ready.
2. Type `a` for **"Yes"** or `b` for **"Not now"**. *(Type `a` to begin!)*
3. Read each of the 14 questions carefully.
4. Type the letter corresponding to your answer (`a`, `b`, `c`, or `d`).
5. After answering all questions, the program calculates your score and reveals your character match with a brief description of their personality.
